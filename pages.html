NEXA × AI FINANCIAL AGENT

02 / SYSTEM

Da pergunta ao insight.
Sem esconder a lógica.

O produto foi desenhado em camadas: onboarding estrutura o contexto; SQLite preserva os dados; serviços determinísticos calculam os fatos; a camada de insights traduz os resultados; a IA entra depois para interpretar e conversar.

01 / INPUT

Guided onboarding

Perguntas estruturadas geram perfil, preferências, categorias, objetivos e regras de acompanhamento.

02 / DATA

Local-first storage

SQLite mantém o contexto financeiro no ambiente local, sem credenciais bancárias ou transações externas.

03 / ANALYSIS

Financial analyzer

Calcula saldo, categorias, orçamento, alertas, comparação mensal e tendências com regras determinísticas.

04 / OUTPUT

Insights layer

Converte métricas em narrativa financeira de leitura rápida e orientada a contexto.

05 / CONTROL

Agent configuration

Consolida preferências, restrições, objetivos e instruções para a futura camada conversacional.

06 / NEXT

Conversational agent

A próxima camada permitirá perguntas em linguagem natural sobre os próprios dados estruturados.

03 / ARCHITECTURE

Separar cálculo
de conversa.

O futuro agente não deve ser a calculadora. Ele interpreta intenção e apresenta resultados; os serviços e o banco continuam responsáveis pelos fatos financeiros.
